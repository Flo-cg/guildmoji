How do I get my token?

Easiest: use Use the saved Discord login above — it reads the session directly from the desktop app on this computer.

  1. Open Discord (desktop app or discord.com/app) and press Ctrl + Shift + I.
  2. Open the Network tab and type api into its filter box.
  3. Click a channel or send a message, then click any request to discord.com/api.
  4. Under Headers → Request Headers, copy the Authorization value. It starts with MTA, NT, or similar.
  5. Paste it into the field above.

Alternative: DevTools → Application (Chrome) or Storage (Firefox) → Local Storage → https://discord.com → token. Copy the value without its quotes.

A token grants full access to your account. This app keeps it in memory only and only talks to discord.com. Never share it with anyone or paste it into untrusted tools.

Runs entirely on 127.0.0.1. Tokens are never written to disk.
