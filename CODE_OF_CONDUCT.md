# Code of conduct

Guildmoji is a small open-source project. Everyone who participates is expected
to make it a welcoming, harassment-free space.

## Expected behaviour

- Be respectful, patient, and constructive.
- Assume good intent and critique ideas rather than people.
- Keep discussions focused on the project.
- Respect privacy: never post someone else's token, personal data, or private
  server content.

## Unacceptable behaviour

Harassment, discrimination, threats, doxxing, sexualized attention, or repeated
disruption are not acceptable. Sharing credentials or private data without
permission is also not acceptable.

## Enforcement

Maintainers may edit or remove comments, close issues, or block accounts that
violate this code. To report a problem, contact the maintainer through GitHub
([@Flo-cg](https://github.com/Flo-cg)). Reports will be handled discreetly.

This code applies in all project spaces, including issues, pull requests, and
discussions.
